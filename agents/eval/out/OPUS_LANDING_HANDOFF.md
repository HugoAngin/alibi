# Passport stream handoff

Execution owns the four web paths in the patch. From the repository root:

```sh
git apply --check agents/eval/out/opus_landing_handoff.patch
git apply agents/eval/out/opus_landing_handoff.patch
cd web
pnpm install --frozen-lockfile
pnpm verify
```

Open `/?view=site` in the local site preview and scroll from the merchant connections through the bank feeds, four-agent investigation, holder approval and signed delivery. The public story is an illustration based on Case 1. Its consent and signature labels are part of that story. Connect and Request use the shared links, and the existing Simulate and Join sections remain available below the stream.

On the detached preview, `pnpm verify` passed with 92 tests and zero Astro diagnostics. Chromium at 1440 × 900 and 375 × 812 exercised all seven stages in both scroll directions, four Connect links and the Request link. The signed package appeared after the approval state. Reduced motion and disabled JavaScript rendered the completed story. The static mobile desk wraps its package label, and the smallest shared controls retain a 24 px height as the board scales. The UNIQLO tile uses a darker red for white-text contrast. The keyless local demo can emit the previously reported Clerk client warning.
