# Evaluator interruption and permission fix

The original capture on application candidate `58bf0d4` stopped after 70 of 132 jobs were attempted: 67 returned predictions, three raised scheduler-level `PermissionError`, and 62 were not started. It is an interrupted evaluation, not a complete unseen comparison. The original lock, predictions and errors remain intact.

The coordinator was manually suspended to investigate earlier generic child exits. A public reproduction confirms that this can trigger a macOS process-group termination race: a child exits during the pause, `communicate()` subsequently times out, and `killpg()` raises `PermissionError`. The previous handler caught only `ProcessLookupError`, so it exited before retaining predictions and logs. This mechanism matches the three empty worker-output directories, although absent original tracebacks prevent proof of each individual exception's cause. The operator pause also qualifies timing evidence for four in-flight workers.

The evaluator now reaps the direct child, still attempts to terminate surviving descendants, and ignores a permission denial only when the direct child has definitely exited. A denial for a live child still propagates. Worker stderr is retained in a private mode-0600 file and is not printed or published.

The public regression used the unchanged candidate, rules Cases 1–4, four workers, the original 30-second rules timeout, the same isolation, and a 31-second coordinator pause. The old handler produced four PermissionErrors; the fix retained four timeout results and their evidence with zero scheduler errors. These are diagnostic timeout results, not correctness successes. `PERMISSION_FIX_PROOF.json` records the counts, source identity and recipe hash. No hidden inputs, gold or model calls were used in the reproduction.

A separate replay-verification problem came from the verification tool's `data` symlink: `/data/` in `.gitignore` ignores directories but not that symlink. The evaluator clean-check now exempts only exact untracked `data` when it is a symlink. It still rejects tracked modifications and every other untracked path. The original evaluator checkout's unused local data directory was preserved outside the checkout so its unchanged historical verifier can run without creating that link; the private pack was not moved.

Lead's rules 7 and 8 permit a disclosed continuation: run the 62 unstarted jobs once, and retry only the three proven scheduler-error groups once. Preserve all 67 returned groups, including earlier generic child exits whose cause is not established. Use the same application SHA, manifest, model configuration, workers, limits and original lock. The original attempt remains evidence; no candidate or answer tuning is authorised by this fix.
