## How it was built

Understanding first: five parallel readers mapped the rules engine, package/approval/policy, store/ingest, templates/CSS and the contracts. The case adapter (`alibi/app/cases.py`) was written and proven on cases 1 and 2 before any route existed. One agent added the template hooks against a written variable spec while the Python was written; a skeptical reviewer re-rendered every page. Four adversarial reviewers (security, correctness, spec, robustness) then attacked the app and each finding was verified before fixing (see the session log in the commit messages).

Defects the smoke tests caught before the suite existed: with a fixed clock two drafts (or two approvals) tie on `created_at`, so the current one must be the last saved (`latest_draft`, `_latest_approval`); the export page summarised attachments from the passport record and leaked an excluded record's id through a fee's `related_record_ids` (now built from the disclosed content only).
